What is a Context Window?

A context window is the amount of information an AI model can consider at one time while generating a response — every prompt, message, and instruction it can actively "see."

Everything inside the window shapes the next response. Everything outside it — doesn't exist to the model.

Context Window vs Memory

Think of it the way a computer separates fast working memory from persistent storage.

Context Window

≈ RAM
  • Temporary
  • Exists only for this conversation
  • Cleared when the chat ends
  • Extremely fast to access
VS

Memory

≈ SSD
  • Persistent, when enabled
  • Carries across conversations
  • Selectively saved & recalled
  • Slightly slower to retrieve

Common Myths

Click a card to flip it and reveal the reality.

MYTH

AI remembers everything forever.

REALITY

It only accesses the current context window unless persistent memory is enabled.

MYTH

Bigger context always means smarter answers.

REALITY

More context helps recall, but reasoning quality depends on the model, not just size.

MYTH

Tokens are the same as words.

REALITY

Tokens are text fragments — punctuation and word pieces both count as tokens.

MYTH

Large context windows replace the need for RAG.

REALITY

RAG still wins for fresh, external, or massive knowledge sources.
